## 서버 배치

서버에서 실제 VNP02IMG·VNP03IMG 한 쌍을 열어 L1B/GEO, I05 LUT의 Kelvin 단위, 원천 6464×6400 배열, UTC 촬영시각, TAI93 스캔 시각을 확인했다. 새 코드는 배치 전 서버 Python 컴파일과 서비스 설정 검사를 통과했다.

기존 코드·일별 보고서는 서버 `/root/viirs/backups/20261122T173220Z`에 보존했다. 원본 R2 Bronze는 지우지 않았다. 기존 transient 작업을 중지하고 저장소의 persistent 서비스를 설치해 재구축을 재개했다. 재부팅 후 자동 실행, 실패 시 재시작, 메모리 상한과 날짜별 체크포인트를 설정했다. 배치 후 재시작 횟수 0, 처음 두 날짜가 진행되는 것을 확인했다.

## 아직 완료로 표시하지 않는 범위

전체 731일은 서버에서 재구축 중이다. 기존 결과와 새 완료 표식 없는 결과가 공존할 수 있어 플랫폼이 게시 상태를 구분한다. 서비스가 동작한다는 이유만으로 전체 기간·전체 행정동 검증 완료로 표시하지 않는다.

NASA CMR 검색에서 짝이 없는 날짜는 별도 상태이며 값을 채우지 않는다. 구름·그림자 QC, 지상 면적을 분모로 한 coverage, 수치팀 강수 정답, Sentinel 보조 자료 결합은 완료되지 않았다. NGII 다운로드 이력은 다른 환경의 원본 보관과 자체 Silver 검증을 대체하지 않는다.
