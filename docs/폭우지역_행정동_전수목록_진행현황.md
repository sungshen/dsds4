## 4. 다운로드 기준 (확정)

1. 범위: 영상이 있는 **시군구 전체 도엽**을 받는다(피해 지역만 고르지 않음).
2. 중복 버전: 같은 도엽이 처리 시점만 다른 두 버전으로 있으면 **최신 처리본 하나만** 받는다.
3. 메타데이터는 영상 zip 안의 `_Aux.xml`을 쓴다. 모자이크는 받지 않는다.
4. **사건 후 영상이 없는 사건(E5·E7)은 제외한다.** 정사영상은 우선 생략한다(1장 약 2.2GB).
