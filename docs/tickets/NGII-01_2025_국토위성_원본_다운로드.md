- 근거 문서: `docs/폭우지역_행정동_전수목록_진행현황.md`

## 범위

사건 후 영상이 있는 사건만 받는다. E5·E7은 사건 후 영상이 없어 제외한다.

| 사건 | 날짜 (전/후) | ARD 도엽 | 정사영상 |
|---|---|---|---|
| E4 2025-07-16~20 | 전 07-08, 07-14 / 후 07-23(정사만), 07-24, 07-25, 07-29, 07-30 | 1,262 | 27 |
| E6 2025-08-13 | 전 07-30 / 후 08-24 | 48 | 2 |
| 합계 | | **1,310** | **29** |

- 도엽 수는 중복을 뺀 값이다. 이웃 시군구와 겹치는 도엽과 처리 시점만 다른 두 버전을 하나로 셌다.
- 정사영상 개수는 서로 다른 ID 개수다.
- 기준
  - 영상이 있는 시군구는 전체 도엽을 받는다.
  - 처리 시점만 다른 두 버전이 있으면 **최신 처리본만** 받는다. ARD ID `L3A_{처리일시}_{촬영일}_{도엽}`에서 처리일시가 큰 것을 고른다.
  - 영상마다 메타데이터(XML·EXCEL)를 같이 받는다. 모자이크는 받지 않는다.

## 저장 구조

```
data/ngii/2025/<event_id>/bronze/originals/<catalog_id>/
    <사이트에서 받은 원본 파일 그대로>      # 이름 변경·압축 해제 안 함
    <catalog_id>.xml / <catalog_id>.xlsx   # 메타데이터
tables/ngii/asset_manifest.csv             # catalog_id, event_id, 촬영일, 전/후, 유형, 파일명, 크기, sha256, 받은 시각
tables/ngii/download_log.csv               # 신청·다운로드 단위 기록(성공/실패)
```

- 브라우저가 `~/Downloads`에 받은 파일을 스크립트가 위 폴더로 옮긴다. 옮길 때 sha256을 기록한다.
- `data/ngii/`는 용량이 커서 git에서 제외한다(`.gitignore`에 추가).

## 절차

1. 사용자가 국토정보맵에 직접 로그인한다.
2. 사건·날짜·시군구별로 검색하고, 최신 처리본만 선택한다.
3. "원본영상 이미지"를 누르면 **다운로드 신청서**가 나온다.
   - 생년월일, 사용목적 유형, 상세 용도를 입력하고 준수사항에 동의해야 한다.
   - 입력과 동의는 사용자가 직접 한다.
4. 받은 파일을 원본 그대로 옮기고, 관리대장(asset_manifest)에 기록한다.
5. 건수를 대조한다. 받은 수가 위 범위 표와 맞아야 한다.

## 확인할 것

- [ ] 신청 후 바로 받는지, 승인을 기다려야 하는지
- [ ] 한 번에 신청할 수 있는 영상 수 한도
- [ ] 파일 형식과 도엽 하나의 크기 (→ 전체 용량과 걸리는 시간 계산)
- [ ] 메타데이터를 영상정보 창에서 한 건씩 받는지, 신청 파일에 같이 들어 있는지

## 예상 소요

- 영상 수: 1,339건 = ARD 1,310 + 정사영상 29
- 신청을 시군구·날짜 단위로 묶으면 **약 60~70회**다.
- 신청 후 바로 받을 수 있다면 2~4시간이다. 신청 1회에 약 2~3분이 걸리고, 사용자가 매번 신청서를 직접 써야 하므로 신청서 작성 시간은 사용자 쪽에 걸린다.
- 승인을 기다려야 한다면 승인 기간만큼 더 걸린다.
- 용량은 첫 다운로드로 도엽 하나의 크기를 확인한 뒤 다시 계산한다.
