# NGII 사건별 인계 자료 — 2026-11-26

기존 관리대장과 보존된 `_Aux.xml`만 정리했다. 새 영상을 받거나 픽셀을 다시 처리하지 않았다. 목적은 주 과제인 **사건별 실제 피해 규모 추정**에 국토위성 자료를 보조 공간 자료로 연결할 준비 상태를 확인하는 것이다.

현재 결과는 **메타데이터 조인 검사 통과, 모델 입력 준비 미완료**다. 1,860개 관리대장·메타데이터·XML이 일대일로 맞고, 이 checkout에서 원본 ZIP은 0개 확인됐다. 다운로드 당시의 체크섬·완료 기록과 현재 파일 접근 가능 여부를 구분한다. 제공기관 ARD, 구름 마스크의 존재, ZIP 무결성은 자체 Silver·구름 QC 완료를 의미하지 않는다. 공식 피해 규모 정답은 결합하지 않았다.

## 제공 파일과 재현

저장소 루트에서 다음 명령으로 같은 기존 자료를 다시 정리할 수 있다. 추가 패키지·인증·네트워크는 필요 없다.

```bash
python3 -I scripts/ngii_delivery_inventory.py
python3 -I scripts/test_ngii_delivery_inventory.py
```

첫 명령은 이 폴더의 생성 파일만 갱신한다. `--reconcile-event-summary`를 추가하면 `tables/ngii/event_summary.csv`도 갱신하고, 기존 초기 AOI 요약이 아직 보존되지 않았을 때 `event_summary_initial_aoi.csv`에 먼저 보존한다. `--verify-raw-checksums`는 현재 로컬에 있는 ZIP만 해시 검사한다. 기본 실행은 원본 존재·크기를 확인하되 원본 바이트의 재검증을 했다고 표시하지 않는다.

## 시간·공간·품질 해석

- UTC 값은 XML의 명시적 `UTC` 요소에서만 읽는다. `first_input_center_*`는 **첫 입력 L2G 영상의 중심 시각**이고 도엽의 정확한 픽셀 노출 시각이 아니다. 7자리 소수초 원문을 보존하고 KST는 UTC+09:00으로 바꿨다. `input_start_min_utc`·`input_end_max_utc`는 XML에 열거된 입력 영상 전체의 시간 범위다. 초기 사이트 검색 화면의 `observation_timezone=unknown` 값은 UTC로 가정하지 않았다.
- raster는 XML에 보고된 EPSG:5179, SR band 2m 격자다. 원래 행·열 GSD와 크기를 보존했고 재격자화·보간·일별 채움·사건 간 합성을 하지 않았다. 이 정리는 원천 관측 횟수를 늘리지 않는다.
- `bbox_*`는 SR1의 네 모서리 경위도에서 구한 외접 범위다. XML의 raster CRS는 명시되어 있지만 이 경위도 값 자체의 datum 표기는 해당 요소에 없으므로 EPSG:4326으로 재지정하지 않았다. 정밀 교차·면적 계산 전에 원본 좌표계와 변환을 확인해야 한다. 외접 범위를 정확한 관측 footprint나 유효 픽셀 면적으로 쓰지 않는다.
- SR1–SR4는 Blue·Green·Red·Near Infrared다. 파장 단위 `nm`와 radiance gain/offset은 XML 보고값이다. ARD 픽셀의 실제 단위·scale·offset·nodata 의미를 원본과 제공기관 정의로 확인하기 전에는 온도나 반사도로 단정하거나 계수를 적용하지 않는다.
- 7개 mask는 NoData·MissingData·Saturation·ValidData·CloudMapHigh·CloudMapLow·Water다. XML 필드 이름은 `PerPixelPercentage`이나 현재 값은 0~1 범위다. 단위 정의를 확인하지 못했으므로 원문을 그대로 저장했고 ×100 변환·구름비율 계산·mask 코드 판정은 하지 않았다. 제공기관 Water mask는 공식 피해·침수 정답이 아니다.
- `rain_region_dongs.csv`·`rain_region_coverage.csv`·`dong_tile_coverage.csv`의 행정동은 **vuski 2021-04**다. VIIRS의 SGIS 2024/2025 2Q와 직접 코드 조인하지 않는다. 기존 coverage는 약 200m 간격 표본점·도엽 번호로 추정한 비율이며 픽셀 단위 실측 QC가 아니다.

## 검사와 남은 인계 조건

검사는 CSV 필수 열·행 폭, catalog ID 및 사건×행정동 중복, manifest↔metadata↔XML 일대일 연결, 메타데이터 주요 값·체크섬 일치, UTC 변환·사건 전후 구분, 네 모서리 범위, 크기·GSD·band 스키마, mask 원시 수치 범위, 같은 날짜·도엽과 체크섬의 중복, 로컬 원본 존재·크기를 포함한다. 이 검사 통과는 메타데이터 정합성 범위다. 원본 픽셀의 결측·이상치·지리 정합·구름 QC는 수행하지 못했다.

2026-11-26 실행에서 메타데이터 검사 오류 0개, 준비 상태 경고 4개를 기록했다. UTC 소수초·날짜 변경, 중복/스키마/값 불일치 감지, 실제 로컬 바이트 해시 검사, 기존 요약 보존, 공유 영상의 사건 연결을 검증하는 8개 회귀 검사가 통과했다. 별도 임시 폴더에서 8개 생성 파일이 바이트 단위로 동일하게 재현되는 것도 확인했다.
