새 위성 관측 수집·crop·Gold 재집계를 실행하지 않았습니다. 데이터는 기존 저장 위치를 유지하고, 사건에 함께 쓰는 영상은 연결표로 표현했습니다. 통계의 null·분모 0·미관측·미검증을 0으로 채우지 않았습니다.

현재 단계에서 **NGII 원본 접근, 자체 구름·그림자 QC, 공식 피해 규모 정답, 행정경계 변환·공통 사건 조인은 미완료**입니다. 인계 자료 검사 통과와 피해 모델 입력 준비를 구분합니다.

파일 체크섬은 [SHA256SUMS.csv](SHA256SUMS.csv)에 있습니다. 공개 GitHub 파일과 7일 R2 공유 안내는 인계서의 접근 절차를 따릅니다. 서명 URL·환경설정·키·서버 백업은 이 폴더에 넣지 않습니다.
