# VIIRS Gold 실제 내용 검사

**검사 결과: 711개 모두 PASS, 7,043,394행.** 유효 픽셀이 없어 온도 통계가 null인 그룹은 53,497개이며, 현재 포함 규칙의 전체 밝기온도 범위는 약 183.24–346.21 K다. 구름 QC 상태는 미검증이다.

기존 R2 Gold 711개, 합계 224,234,595바이트를 대상으로 한다. Silver·원본을 다시 처리하거나 Gold를 재생성하지 않는다. 실제 검사 결과와 실패 여부는 [gold_validation_summary.json](gold_validation_summary.json), 날짜별 결과는 [gold_validation.csv](gold_validation.csv)에 있다. 모든 파일이 PASS여야 상위 인계 자료와 공유 링크를 발행할 수 있다.

## 확인하는 내용

- 네트워크 요청 전에 전체 목록의 SHA-256·ETag·크기·필수 일별/장면별 기대값과 Silver 계보가 완전한지 확인한다.
- 기존 Gold 전체 바이트의 SHA-256과 크기를 완료 표식에 선언된 값과 대조한다. 검증된 바이트는 Git 제외 로컬 캐시에서 이후 재사용할 수 있다.
- 실제 Parquet의 15개 열·자료형·K/TAI93 단위와 날짜·경계·처리 코드·입력 Silver 해시를 대조한다.
- `(dong_code, swath_id)` 중복, 8자리 동 코드, 필수 식별자·시각·개수의 null을 검사한다.
- 픽셀/유한 온도/QA 제외/유효 개수의 상·하한과 실제 장면별·일별 합계를 독립 Quality/서버 최종 기록에 대조한다.
- 유효 픽셀이 0개인 그룹의 온도 통계가 null인지, 유효 온도가 유한한 양수 K인지, 최소≤평균≤최대인지 검사한다.
- `valid_fraction = valid_count / pixel_count`와 0–1 범위, 스캔 시작 시각의 유한성·순서 및 장면 UTC 시작 시각을 대조한다.

전체 Gold 행 수는 행정동 개수가 아니라 **동×장면 그룹 수**다. 픽셀 수에는 반복 관측이 포함된다. `groups_without_valid_temperature`는 삭제하거나 0 K로 채울 그룹이 아니라 온도 통계가 null이어야 하는 그룹이다.

## 검사 범위와 활용 제약

온도 최저·최고 값은 현재 QA 포함 규칙으로 관측된 범위다. 임의의 기후 임계값으로 이상치를 제거하지 않았으며 과학적 온도 편향·대기 보정·구름·그림자 검증을 완료로 표시하지 않는다. `cloud_qc_status`는 `unverified`다. 전체 Silver·Bronze 바이트를 다시 읽지 않았고 픽셀 단위 재집계도 수행하지 않았다.

검증된 동일 바이트를 재사용하려면 저장소 루트에서 다음을 실행한다. 네트워크에 있는 새 영상은 수집하지 않는다.

```bash
.venv/bin/python scripts/verify_handoff_gold.py --reuse
```

`--reuse`는 소스·기대값·검사 코드 지문이 모두 같은 PASS 기록만 재사용한다. 바이트 캐시는 크기와 전체 SHA-256을 다시 확인한다. 조건이 바뀌면 기존 Gold를 다시 검사하며 결과를 덮어쓰거나 재처리하지 않는다.
