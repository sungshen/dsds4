# 2026-11-23 실제 관측 시험 학습

이 기록은 **사건을 선택한 작은 기술 시험**이다. 양성이 있는 날짜를 관측값 확인 후 골랐으며 일반적인 발생률이나 예측 성능을 추정할 표본이 아니다. 이 결과를 실전 폭우 예측 모델의 성능으로 사용하지 않는다.

## 수집·정렬

- 기상청에 직접 요청한 AWS 강수 192시간(후보 날짜 8일)을 원본·checksum과 함께 로컬 보존했다.
- 시험 학습에는 2024-07-17, 2024-07-23, 2025-08-13의 세 강수 날짜를 사용했다.
- 위성 원본 81개를 확보했다. 그중 3개는 기존 Bronze를 검증해 재사용하고 78개는 직접 추가 수집했다.
- 서울 108 지점 중심 원천 2 km 격자 64×64 patch와 mask를 만들었다. 네 시각의 영상과 다음 1시간 강수 정답을 결합했다.
- 준비된 69표본을 날짜로 분리했다. 학습 23개(양성 2), 검증 23개(양성 1), 시험 23개(양성 1)다. 불완전 시간 이력과 강수 누적은 제외했다.
- 수치 기상 변수의 실시간 제공 시각이 검증되지 않아 이 실행에서는 추가 입력으로 사용하지 않았다. 수치 강수 관측은 정답으로 사용했다.

## 학습 결과

PyTorch CPU, seed 42, 영상 8채널 CNN, weighted BCE, batch 16, 20 epoch를 사용했다. 검증 AP로 epoch 2를 선택하고 검증 F1로 확률 기준을 정했다. 시험 자료에 맞춰 다시 튜닝하지 않았다.

시험의 폭우 **1건은 미탐**, 비폭우 22건 중 **6건은 오탐**이었다. 나머지 16건은 참음성이다. F1·recall은 0이다. Brier score는 단순 학습 발생률 baseline보다 나빴다. **유효한 성능을 확보했다고 볼 수 없다.** 표본과 양성이 매우 적으며 사건 선택에 따른 편향이 있다.

[metrics.json](metrics.json)에 AP·정밀도·재현율·F1·Brier와 baseline을 모두 보존했다. [test_predictions.csv](test_predictions.csv)는 시험 시각별 정답과 확률이다. 이 파일의 높은 정확도나 AP의 작은 차이로 성능 향상을 주장하지 않는다.

## 재현과 보관

[실험 설정](config.json), [자료 요약](data-summary.json), [학습 이력](history.json)을 보존한다. 설정의 입력 경로는 프로젝트 폴더 기준으로 상대화했다. 원본 영상·강수 응답·patch·실제 checkpoint는 프로젝트의 Git 제외 `data/`, `runs/pilot-20261123/`에 있다. `metrics.json`의 checksum으로 연결한다.

반복 실행은 동일한 계획·자료·seed·학습 조건을 재현하는 검사이며 시험 성능을 보고 조건을 바꾼 새 모델 탐색이 아니다. 구체적인 비교 결과는 `reproduction.json`에 기록한다. 재현 명령은 [프로젝트 README](../../README.md)에 있다.

다음 과제는 전체 기간을 연속 수집하고 시험 구간을 미리 고정한 뒤 독립적인 폭우 사건을 충분히 확보하는 것이다. 현재 정답은 서울 한 관측소이며 행정동 전체 강수 정답으로 복제하지 않는다.
